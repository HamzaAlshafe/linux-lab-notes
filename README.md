# Linux Lab Notes

My notes from the Linux Administration Lab (Computer Systems Engineering, AAUP), as a PowerPoint deck.

**File:** `Linux_Lab_Notes.pptx` (51 slides)

## Contents

1. The big picture: system layers, users, the prompt, the file system tree
2. Users and sessions: `su`, `sudo`, `who`, `id`, getting help
3. Moving around: `pwd`, `cd`, absolute and relative paths, `ls`
4. Shell basics: `echo`, variables, history, Ctrl keys
5. File operations: `touch`, `mkdir`, `rm`, `cp`, `mv`
6. Viewing files: `cat`, `more`, `less`, `head`, `tail`
7. Redirection and piping: `>`, `>>`, `<`, `|`
8. Searching with `grep`
9. Disks and file systems: `fdisk`, `lsblk`, `df`
10. Lab tasks with solutions

The deck is updated after each lab.
